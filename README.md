# FindMe – GitHub Pages PWA

Reine HTML/CSS/JavaScript-PWA. Einträge werden ausschließlich im lokalen `localStorage` des Browsers gespeichert.

## Veröffentlichung
Repository auf GitHub anlegen, diese Dateien in `main` laden und unter **Settings → Pages** `main` / `/ (root)` als Quelle auswählen. Danach die angezeigte `github.io`-Adresse auf Android öffnen und im Browser **Zum Startbildschirm hinzufügen / Installieren** wählen.

Die Seite funktioniert ohne APK und ohne zusätzliche App. GitHub Pages hostet statische Dateien direkt aus dem Repository; GitHub-Pages-Seiten unterstützen HTTPS. Die GitHub-Seite selbst ist öffentlich erreichbar, die FindMe-Einträge werden jedoch nicht ins Repository hochgeladen.
