# FindMe

Eine moderne, vollständig lokale Android-App zur Erfassung von Datum + „Hoden gefunden: Ja/Nein“.

## Eigenschaften
- Aktuelles Datum ist beim Start vorausgefüllt.
- Dropdown: Ja / Nein.
- Einträge werden direkt auf dem Gerät in `SharedPreferences` gespeichert.
- Keine Cloud, kein Server, keine externe Datenbank und keine Berechtigungen.
- Material-3-Oberfläche, Hell-/Dunkelmodus passend zum System.
- Einträge können einzeln gelöscht werden.

## GitHub / lokaler Betrieb
Der Quellcode kann in ein GitHub-Repository gelegt werden. Die App benötigt zur Laufzeit weder Internet noch einen Account.

Hinweis: Für das Kompilieren einer Android-App wird normalerweise eine Android-Buildumgebung (z. B. Android Studio/Gradle) benötigt. Die fertige ZIP enthält den vollständigen Quellcode, aber kein vorgebautes APK.
